How we know

The optimizer was asked for progressively larger renditions of one 692 px source. It caps at the source width and stops — there are no more pixels to give:

source = 692 × 519

  asked w=640    →  got 640 × 480
  asked w=1080   →  got 692 × 519
  asked w=1920   →  got 692 × 519
  asked w=2560   →  got 692 × 519   ← capped at source

The layout container is 1408 px of content (max-w-368 minus lg:px-8). A half-width gallery cell is therefore (1408 − 24) / 2 = 692 px and a three-column card is (1408 − 64) / 3 = 448 px. Those are exactly the dimensions the files were saved at — 692×519 and 448×504. Pixel-perfect on a 1× monitor, soft on every retina display.

Opening a file directly looks sharp because it displays at its native size. Nothing is being stretched.
